# Laboratoria ORM

Każdy moduł będzie zawierał:
- cel i wymagania wstępne;
- komendy przygotowania środowiska;
- zadania wykonywane krok po kroku;
- kod referencyjny;
- zapytania SQL i instrukcje ich analizy;
- zadania samodzielne i kryteria weryfikacji.

## Moduły
1. Pierwszy projekt EF Core i połączenie z SQL Server
2. Encje, DbContext i migracje
3. Mapowanie relacji i Fluent API
4. LINQ oraz generowany SQL
5. CRUD i Change Tracker
6. Transakcje i współbieżność
7. Wydajność: N+1, Query Store, plany
8. Podsumowanie i prezentacja projektów

Materiały robocze: szczegółowe instrukcje będą w osobnych plikach `lab-01.md` itd.

## Przed Lab 01

Zainstaluj narzędzia i wykonaj testy według [instrukcji przygotowania środowiska](../docs/przygotowanie-srodowiska.md).

Instancję SQL Server 2022 CU26 uruchamiamy według [Docker Compose](../docs/docker-sql-server.md).
