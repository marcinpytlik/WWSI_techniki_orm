# Projekt zaliczeniowy — propozycja

## Temat
System obsługi zamówień (klienci, produkty, zamówienia, pozycje zamówień) z wykorzystaniem C#, EF Core i SQL Server.

## Minimalny zakres
- Co najmniej cztery encje i relacje 1:N.
- Konfiguracja DbContext; część mapowania przez Fluent API.
- Migracje inicjalne i co najmniej jedna migracja zmieniająca schemat.
- CRUD z walidacją wejścia i obsługą błędów.
- Zapytania LINQ: filtrowanie, sortowanie, agregacja i projekcja.
- Analiza co najmniej dwóch zapytań wygenerowanych przez EF Core (SQL i wpływ na wydajność).
- Instrukcja uruchomienia.

## Rozszerzenia
- Optimistic concurrency (np. rowversion).
- Transakcja obejmująca kilka zmian.
- Demonstracja problemu N+1 i jego eliminacji.
- Testy integracyjne na rzeczywistej bazie testowej.

Szczegółowe kryteria oceny wymagają zatwierdzenia przez prowadzącego.
