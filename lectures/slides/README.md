# Wykład 01 — prezentacja

Prezentacja `01-historia-orm.marp.md` zawiera 17 slajdów w formacie [Marp](https://marp.app/) (Markdown + slajdy) i notatki prowadzącego w komentarzach HTML.

## Otwieranie i eksportowanie

1. Zainstaluj [Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode).
2. Otwórz `01-historia-orm.marp.md` i włącz podgląd Markdown (`Ctrl+Shift+V`).
3. Z palety poleceń VS Code wybierz **Marp: Export Slide Deck** i format PDF lub PowerPoint.
4. Sprawdź wygenerowany plik na docelowym komputerze projektora.

## Czas

Docelowo 45 minut. Podane komentarze są wskazówkami do omówienia, a nie dosłownym skryptem do czytania. Szczegółowy tekst znajduje się w [scenariuszu wykładu](../01-wprowadzenie-do-orm.md).
